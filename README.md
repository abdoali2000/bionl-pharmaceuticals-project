# Bio NL Pharmaceuticals

A bilingual (Arabic/English) pharmaceutical products catalog and ordering platform with a full admin dashboard for managing products, categories, offers, and customer orders.

---

## 🚀 Project Overview

This project is designed for Bio NL Pharmaceuticals to showcase and manage pharmaceutical products in a modern, SEO-friendly, and fully dynamic web application.

The system supports:

* Product browsing and search
* Product details pages with SEO-friendly URLs
* Online order submission with payment proof upload
* Admin dashboard for full content management
* Contact form with message storage
* Promotional offers system

---

## 🧱 Tech Stack (Planned)

* Frontend: Angular (SSR enabled)
* Backend: NestJS (REST API)
* Database: PostgreSQL
* ORM: Prisma
* File Storage: Cloudinary
* Automation: n8n Webhooks

---

## 🌐 Features

### Public Website

* Home page with featured products
* Products catalog with search and filters
* Product details pages (SEO-friendly)
* About Us page with company timeline
* Offers page with promotions
* Contact form

### Orders System

* Add products to cart
* Submit orders
* Upload payment proof
* WhatsApp ordering support

### Admin Dashboard

* Secure login (predefined admins)
* Manage products (CRUD)
* Manage categories
* Manage offers
* View orders
* View contact messages

---

## 📦 Key Concept

The system is fully data-driven:

> Any new product added via the admin dashboard automatically appears across the entire frontend without any code changes.
